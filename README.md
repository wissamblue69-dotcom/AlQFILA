# AlQFILA

المستودع التنفيذي الأساسي لمشروع القافلة. سيضم خدمات Python/FastAPI، وبيئة Docker المحلية، والبنية التحتية ككود Terraform لمنصة Google Cloud Platform.

تبقى الرسومات والتوثيق والقواعد الحاكمة في مستودع [qafila-systems-architecture](https://github.com/wissamblue69-dotcom/qafila-systems-architecture).

هذا الالتزام يهيئ الفرع الأساسي فقط. ستصل التأسيسات التنفيذية عبر Pull Request مستقل للمراجعة.
